# engineering/

Skills for day-to-day code work — designing, building, documenting, reviewing,
and auditing software projects.

## [`autonomous-loop`](./autonomous-loop/SKILL.md)

Takes a briefed backlog to a safely-running unattended agent loop — owns the stop condition, HITL→AFK graduation, iteration/cost/time cap, and monitor/stop/resume.

## [`doc-it`](./doc-it/SKILL.md)

Generates or patches reference documentation (README, API docs, onboarding guide, CHANGELOG) from source, and audits ADRs and CONTEXT.md for staleness.

## [`flow-pr`](./flow-pr/SKILL.md)

End-to-end PR helper: cuts a branch, commits → pushes → opens PR, reviews the diff, gates on CI, and merges to the default branch.

## [`frontend-design`](./frontend-design/SKILL.md)

Designs and refines production-grade, opinionated frontend interfaces — from prose direction through tokens, components, and accessibility audit.

## [`repo-audit`](./repo-audit/SKILL.md)

Multi-phase orchestrator that audits a repo end-to-end (code, tests, CI/CD, security, docs, issues) and synthesizes findings into a prioritized backlog.

## [`software-design`](./software-design/SKILL.md)

Turns a PRD and published backlog into named modules, explicit seams, a testing strategy, and TDD-ready issue bodies.

## [`staleness-audit`](./staleness-audit/SKILL.md)

Audits pinned toolchain versions (runtime, language, container, CI matrices) for staleness and emits a ranked report; applies safe in-major bumps automatically.
